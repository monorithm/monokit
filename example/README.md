# Monokit scenarios

This application demonstrates Monokit through eight polished, responsive
product scenarios rather than a component catalog:

- Creator studio
- Storefront
- Checkout
- Order tracking
- Team workspace
- Live commerce studio
- Conversation
- Group call

Every screen is composed directly from public Monokit widgets. Interactions,
responsive layouts, light/dark themes, honest system states, media surfaces,
and commerce patterns are exercised in context.

Run it in Chrome:

```bash
flutter run -d chrome
```

Or build an Android debug APK:

```bash
flutter build apk --debug
```
